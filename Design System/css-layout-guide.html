Layout CSS Grid

Estrutura de layout responsivo com CSS Grid e Container Queries.

css
/* Container padrão */ .container { max-width: 1200px; margin: 0 auto; padding: 0 var(--space-5); } /* Grid responsivo sem media query */ .auto-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr)); gap: var(--space-4); } /* Centering perfeito */ .center { display: grid; place-items: center; } /* Fluid type scale */ .t-hero { font-size: clamp(32px, 6vw, 80px); letter-spacing: -0.04em; line-height: 1.05; }

Fundamentos

Princípios de Design

Hierarquia clara

Espaçamento e tipografia criam hierarquia visual sem depender de cor como único diferenciador.

Performance first

Animações usando transform e opacity, aceleradas por GPU. Sem layout thrashing.

Mobile First

Layout construído para 320px e expandido com min-width. Touch targets de 44px mínimo.

Acessibilidade

Focus rings visíveis, contraste WCAG AA, semântica HTML correta e suporte a motion-reduce.
