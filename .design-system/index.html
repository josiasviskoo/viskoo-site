Viskoo Design System

Referência completa de tokens, componentes e padrões visuais utilizados em todo o site da Viskoo. Todas as páginas de produto importam index.css da raiz do projeto — essa é a fonte única da verdade.

Design Tokens

Todas as variáveis CSS estão declaradas em :root no arquivo index.css. Nunca use valores hardcoded — sempre referencie um token.

index.css — :root 
/* Cores */
--bg-base:        #080808;     /* fundo mais escuro */

--bg-elevated:    #1a1a1a;     /* superfícies elevadas */

Animações

Animações de entrada são aplicadas via stagger no atributo animation com delay incremental.

CSS — Padrão de stagger
/* Elemento 1 */
animation: fadeUp 0.6s var(--ease-out) 0.1s both;

/* Elemento 2 (delay +0.1s) */
animation: fadeUp 0.6s var(--ease-out) 0.2s both;

/* Elemento 3 */
animation: fadeUp 0.6s var(--ease-out) 0.3s both;

/* Float contínuo em ícones */
animation: float 4s ease-in-out infinite;
.icon-wrap:nth-child(2) { animation-delay: 0.6s; }
.icon-wrap:nth-child(3) { animation-delay: 1.2s; }
